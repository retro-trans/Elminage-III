# Elminage III (PSP, ULJM05883 v1.03) — data formats

All addresses are for the decrypted EBOOT (`work/source/EBOOT.elf`, dumped by PPSSPP,
single PT_LOAD at 0x08804000, filesz 0x3C1500, memsz 0x7F1580).

## Disc layout
- `PSP_GAME/SYSDIR/EBOOT.BIN` — encrypted; the build replaces it with the patched plain ELF
  (needs CFW / PPSSPP; document for real hardware).
- `PSP_GAME/USRDIR/*.BIN` — Mps2 archives: PARTS, ETC, ANIME, 3DPARTS, BTL, SCP.
  (`*_.BIN` next to them are small encrypted side files, not touched.)
- `PSP_GAME/INSDIR/*` — install-data copies (game can install to Memory Stick). Not used
  for loading when not installed; keep in sync if we ever support install mode.

## Mps2 archive (`tools/mps2.py`)
- 0x00 'Mps2', 0x04 u32 count N, 0x18.. N entries of 0x18: u32 offset, u32 size, char name[16].
- Header words from index 6 up to (N+1)*0x18 XOR KEY[255-(i&0xff)], KEY = 256 u32 @ 0x08974378.
- Every file, at load (0x08916204, 0x089162A4):
  - first 8 words XOR (~offset + size) - 0x3E5*i (offset/size = its TOC entry);
  - for each char c of its uppercased name: byte[0x20 + 7*c] ^= ~c.
- `extract` removes both layers; `build` re-applies them with the new offsets.

## ETC.BIN text tables
CSV files (Shift-JIS) parsed at boot (`0x0891A7BC` opens `data/csv/<name>.csv`), then freed.
Binary `*CSV.BIN` siblings exist (ITMCSV.BIN etc.) — check which the game reads before editing.

## Fonts (ANIME.BIN)
- `FONT16_01..08.GIM`: full-width SJIS 16x16 sheets (256x512 idx8, 16 cols x 32 rows).
- `FONT10_16.GIM`: half-width ASCII/kana, 10x16 cells, 25 per row, starts at 0x20.
- `FONT12_12.GIM`, `FONT08_08.GIM`, `FONTW20_32`, `FONTB20_32`, `FONTF10_16`: other fonts.
- Font object (vtable 0x08978CF0): +4 cellW, +8 cellH, +0xC cols, +0x10 glyphs/sheet,
  +0x14 halfW (10), +0x18 halfH, +0x1C half cols (25), +0x2C first half sheet index,
  +0x30.. texture handles, +0x90 line height, +0x94 clip flag, +0x98 clip x.
- Draw string `0x0891BAF8(font, x, y, color, t0, t1, str)`: 0x0A newline, 0x20 advance
  font[0x14] if half sheets exist, ASCII/kana 0x20-0x7E / 0xA1-0xDF use the half sheet
  and advance font[0x14] (fixed 10px) — VWF hook point. Glyph lookup `0x0891C0AC`.

## Scripts (SCP.BIN → SCDxx.BIN, `tools/scp.py`)
- Original: one bump buffer @ 0x08C88064, size 0x130000 (SCDWMAP + current chapter).
  Patched (0.1.3): SCDWMAP alone in that buffer; chapters in a 0x80000 buffer at 0x09035600
  (loader 0x0889641C, hook at 0x08896488; chapter load 0x08896650 restores the post-WMAP snapshot).
- SCD file: u32 dir_size; entries: byte t (t&0xC0 0x80=file/0x40=dir, t&0x3F=len),
  file: u32 off, u32 size, name; 5-digit prefix of name = script id (table @ 0x08C87864).
- Sub-script: u16 0, u16 size-6, code. base = off+4; jumps/calls are u16 offsets from base.
- VM dispatcher 0x0888F074 (ctx a0, op a1; ctx+0x528 read ptr, ctx+4 base).
  Opcode u8, `FF xx` = 0x100+xx. Operand signatures: `work/source/scp_sigs.json`
  (generated by `tools/scp_sig.py`): ARGS n = u16 mask (2 bits/arg: 0 u8, 1 s16, 2 u32, 3 var)
  + values. Op 0x0D = switch (s16 case/offset pairs until case 0xFFFF + default).
  Op 0x92 = choice menu (count, prompt offset, flag; count x (u8, s16 text off, s16 code off)).
  After an unconditional jump (op 0x0A) a sub-script may keep strings (prompts, unreferenced text) before the
  next code target: scp.parse_file(d, skip_dead=True) reads them as strings (tools/scp_extra_dead.py).
- Strings: inline SJIS, ESC 0x1B xx; 1B 00 ends; 1B 0B/0C/0E/11/12/13/14 have 4 operand
  bytes (runtime inserts). Parser/copy routine `0x08897804(…, dst, src, …, &consumed)`.
- String operands by offset (resolved by 0x08893D48 = base + off): 08F a1, 092 a1 + choices,
  0A2 a2, 10A a1, 12A a1, 12B a1, 12D a1, 12F a0.
- Translation strategy: keep script byte layout; replace string slots with a marker and pack
  English into free slot space (or space appended to the file) with continuation links; a hook at
  0x08897804 reassembles the string. No jump offsets change. Encodings (7-bit bytes, high bit set):
  - `1B 7D r r r l l` slot of >= 7 bytes: r = 21-bit signed offset, l = 14-bit slot length.
  - `1B 7A r r r l`   slot of exactly 6 bytes: l = 7-bit slot length.
  - `1B 79 r r`       slot of exactly 4 bytes: 14-bit offset, text within +-16 KB, no continuation.
  - `1B 7E r r r`     continuation link inside packed text.
  - r counts 2-byte units from (address of the marker & ~1); packed chunks start at even addresses
    (range +-2 MB; SCDWMAP is about 1.1 MB). tools/text_build.py.

## Script variables
- Op 0x3D (ARGS 2): var[arg0] = arg1. Op 0x0F (ARGS 3): var[arg0] (op arg1: 0 set / 1 add / 2 sub) arg2.
  Setter 0x08894278 (ctx, id, value). Op 0x0D switch: ARGS(1) value, then raw u16 (case, offset) pairs,
  terminated by FF FF FF FF; falls through when no case matches.
- Globals: *(u32 *)0x08C87860 (= 0x08BE7E90, game state) + 0x20534 + 4 * id, 5000 of them, cleared at
  New Game (0x088975C0) and part of the save (GAMEDAT.BIN). The scripts use ids up to 396.
- Var 4990 = text font chosen at New Game (patch): 0 not asked / 1 original / 2 HD (tools/vwf.py FONT_VAR).
- Op 0x92 choice: ARGS 3 (count, prompt offset, flag), then count x (u8 index, s16 text offset, s16 code
  offset); the chosen entry's code runs and returns with op 0x09. Ops 0x91 / 0x8C take one s16 (5 bytes).

## Name entry editor
- State *(u32 *)0x08BE7094: +8 text as 2-byte cells, +0x2210 cursor, +0x2212 saved cursor, +0x2214 page,
  +0x220A max cells, +0x2E4 character record, +0x2E8 mode (0x7C/0x9D/0x15E title, 0x7D/0x9E/0x15F name,
  0x7E/0x9F/0x160 nickname, 0x15C Book of the Next Age password, 0x174-0x177 multi-line texts).
- Keyboard: 15x6 cells per page, row pointers at 0x08963358 (81 pages); row 5 cols 12/13/14 = left/right/end.
  Grid draw 0x088532E4, key handler 0x08853514, backspace 0x088536A0, cursor xy 0x08853014,
  char filter 0x0885376C. Record fields: name +0x00 (0x14), title +0x19 (0x10), nickname +0x32 (0x14).
- Patched by tools/name_entry.py (Latin keyboard, ASCII storage).
