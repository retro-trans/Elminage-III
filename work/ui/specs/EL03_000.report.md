# EL03_000 UI texture report

Sheet: ANIME/EL03_000.GIM. Spec: work/ui/specs/EL03_000.json (generated by a scratch script, 600 erase ops, 116 labels).
Preview: work/ui/preview/EL03_000.png. Build output: work/build/img/EL03_000.GIM.

Japanese texts found: 116 (counting every state/copy of a plate separately). Translated: 116. Unreadable / unfit: 0.
Not translated (not Japanese): the two 5x5 plates, digits 1-5 / 0-19, ":" "( )" "No TITLE No GP NAME" pieces, X:/Y:, NAME/LV/RECORDED HISTORY etc.

## Method
- Font: the game's 12px font everywhere (the 16px font is 13px tall and does not fit the 11-12px rows), spacing 1, falling back to 0
  when needed (noted per row). Exception: Monster Alert plate (14px original) uses the 16px font.
- Option-name column (x0-119, 22 rows of 12px from y66): the SE Volume row was cleaned with copy:30 (bg is flat from x18),
  then its rows dy0-10 were blitted to the other 21 rows; 26 glyph pixels that touched the gold separator lines were re-blitted
  one by one from the clean separator (y101). English right-aligned at x112 like the original, max 104px.
- Value plates (black = normal, red = selected; columns x120/192/264(narrow 48px and wide 72px)/336, 12px tall): per
  (column, colour) group, the plate with the narrowest text is cleaned with copy: from a column just left of the text, then the
  text span is blitted from it to the other plates of the group. English centred in the plate, max plate width - 8.
- Brown label plates (HP/AC, Style/Face Load, Auto-Admit, Town/Status/Battle, Password, Book): copy: from a clean column left of
  the text (Face Load plate: interior blitted from the cleaned Password plate, same template). Right-aligned at the original
  right edge.
- Title bars and records header plates: copy: from a fully dark column (left of the text or a gap between glyphs), caps,
  swirls and bow-tie dividers kept; English centred, kept between caps/dividers.
- Map legend (text on transparent, 2-row bar under each entry): text rows filled transparent; bar columns touched by glyphs
  re-blitted from an entry whose bar is clean at that column. Text colour 250,220,195 (original), no outline.
- Pink record pieces (cycle / status) and the Fame heading: filled transparent, redrawn (Fame with a 1px dark outline like the
  original shadow).

  Off for both nashi plates (eboot uses "None" for the bare word; here it pairs with On/Large/Small).

  495, right column x454-511); "Conveyor" uses x454-511 (1px left of the original start).
  Record pieces "Run" (x91-115) and "Stat" (x172-196) stay inside the gap before the next fixed piece but are wider than the
  original glyphs (20px); check in-game for clipping.
- The Book of the Next Age header row (Current/Saved/Rare Rate+/...) meaning was inferred from layout + HELP text; verify in-game.
- Value text drawn with spacing 0 (No Change, Real Name, Nickname, Keep as is, Clear Blue, Step Back, Facing Up, Don't Use)
  is tight; readable in the preview.
