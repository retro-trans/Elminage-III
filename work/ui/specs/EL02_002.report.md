# EL02_002 - menu buttons (temple / castle / training hall / camp / system)

Spec: work/ui/specs/EL02_002.json. Preview: work/ui/preview/EL02_002.png.

Texts found: 28 distinct labels, 84 sprites (every label in 3 states: selected / normal / disabled). Translated: 84/84. Nothing else on the sheet contains Japanese (the rest is transparent).

## Layout
- Group A: 114x18 plates, columns selected x0 / normal x114 / disabled x228, rows y = 20*r (r 0-14). Same plate art as EL01_000.
- Column x342, rows 0-8: Save / Suspend / Options with their 3 states stacked vertically (sel, nor, dis). The selected and normal plates are identical to group A; the disabled plate is a variant (brighter swirl, swirl and bottom border shifted 1 px right from rel x80).
- Group B: 96x18 plates, columns x0 / x96 / x192, rows y = 20*r (r 15-24). Swirl starts at rel x72 (group A: rel x90).

## Method
- Reference plates: Pray (row y20) for A, Back (row y420) for B. Selected references cleaned with `copy:` of a plain gradient column (A rel x68, B rel x58); normal/disabled references cleaned by blitting texture from the same plate to the right of the text (A rel 51-88 -> 12-49, B rel 42-70 -> 12-40), so the noise texture stays and no streaks appear.
- Every other plate gets rel x12-113 (A) / x12-95 (B), all 18 rows, blitted from the reference of its state (cols 0-11 were verified identical on all plates and contain no text). Column-x342 disabled plates get only rel x12-79 from the group A disabled reference and keep their own swirl/border from rel x80 (seamless, checked at 7x).
- Text: 16 px game font, left-aligned from rel x13 (rel x12 with inset 0 for People Index, Change Class, Appraise All), 1 px outline. Colours sampled from the original glyphs: selected fill 255,255,255 / outline 60,6,107; normal fill 220,240,241 / outline 13,15,27; disabled fill 61,61,61 / outline 6,5,10. (EL01_000 uses slightly different colours. These are sampled from this sheet.)
- Text area: A up to rel x88 (swirl at x90), B up to rel x70 (swirl at x72).

## Open points
- 図鑑 had no established English. Bestiary / Item Index / People Index were chosen to fit. The parent help text says "Browse the encyclopedias...", so the reviewer may want to align that wording.
- Appraise All overlaps the swirl in group B (see above). It could be shortened to "Appraise" if overlapping is not acceptable.
- Disabled text is dim (61 grey), matching the original's dimness.
