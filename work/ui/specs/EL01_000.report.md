# EL01_000 - UI texture report

Preview: `work/ui/preview/EL01_000.png` (build: `python tools/img_text.py work/ui/specs/EL01_000.json`).
The first button group (y 96..213: Inspect / Appraise All / Reorder / Talk / Back / World Map) is the
original worked example and is unchanged. Everything below was added to the same spec.

## Method
- 95-wide buttons (呪文 ... 鑑定する): reference row 呪文 (y 216) cleaned with `copy:` (column x0+44); every
  other 95-wide row is blitted from it; label left-aligned at x0+13, colours/outline as in the first group.
- 59-wide buttons (使う/渡す/捨てる): reference row 使う (y 376) takes columns 12..39 from the cleaned 95-wide
  art (same gradient; left edge verified identical); other rows are blitted from it. The 60-wide 戻る column
  (x 192) is the same art (columns 0..12 and 39..58 identical) and is blitted from the matching state.
- Title plates and the 6 small dark plates: text area refilled with a clean column inside the plate
  (`copy:`); white 12 px text with a 1 px dark outline.
- 追加/戻す plate: both cells refilled with their flat background colour (the texture is noise, no clean source).
- Glyph strips (pink on transparent): erased with `fill:0,0,0,0`; labels in (255,224,201), 12 px font,
  centred on the original word. Kept as is (not Japanese): ＬＶ, ＥＰ ＨＰ, ＡＣ (row y 292), ＥＰ ＧＰ, ／／, ％, ～,
  the colon after 倍打 and the dot next to it, L/R arrows, icons, EMPTY, NAME, STYLE/FACE LOAD, EXTRA SKILL,
  MAGIC and SKILLS, DEFAULT, Music/Picture Folder, GP, Sound List, GAME START, DATA INSTALL.
- Checked with an erase-only render: no Japanese pixels left.

## Risk: unknown sprite rects
The game's UV rects for the strip pieces are not known. Labels stay inside the original word's cells where
possible; where English needed more room it extends into free space beside the word (noted below). If the
game blits a rect tight to the original kanji, those labels would be clipped at the edges. Check in game:
item/monster info, character list, resist & slaying screen, action routine screen.

## Glyph pieces (single kanji / short words)
- 頭 体 手 足: Head / Body / Hands / Feet (eboot terms), wider than the 12 px kanji; the neighbours leave room.
- 善 / 中立 / 悪: G / N / E (the game's own Ｇ/Ｎ/Ｅ codes). 中 and 立 are treated as one word.
- 火 / 氷 / 雷: F / I / E (12 px cells; two-letter forms ran together). 神聖 Hly, 暗黒 Drk (24 px cells).
- 回: "x" (counter suffix). ～ kept.
- Monster-type columns (12x24, two kanji stacked): two-letter code stacked one letter per cell
  (Mc Ud Sp In An My Gh De Dg Fi Ma Pr Th Bf Gi Di). Codes reuse the eboot abbreviations; Mc (Magical
  Creature), De (Demon) and Ma (Mage) are new because the eboot has none for those types.
- Status columns (24 px each): Slp Psn Par Sil Cnf Cha Pet.

## Open points
- 戻す = "Back" is a guess at the screen (return an item to the item list); "Return" or "Remove" do not fit 30 px.
- 性別 uses "Sex" although the glossary term is "Gender" (no room in 24 px).
- Character-list header (ＬＶ ニックネーム 種族 性別 年齢 性格 職業) is tightly packed: Nickname Race Sex Age Aln Cls.
- Nothing left unread; every Japanese text on the sheet has a label.
