Method
- Plates are 136x16 cells (3 columns at x 0/136/272, 32 rows). Text area x+3..x+132, y+1..y+14; rows y+0 and y+15 are the grey frame.
- Orange plates: interior blitted from the empty orange plate at (136,384) (identical background).
- Blue plates (col 1 rows 0-8): plate 3 (Ancient Rites) cleaned by tiling flat columns x28..47 over the text (x50..85), then its interior blitted to the other 8 blue plates.
- Text: 16px font, white, no outline (the original glyphs are plain white), centred in a 124px area; spacing 1, falls back to 0 for long names.
- 16px descenders (g j p q y) reach the frame row y+15; extra pseudo-labels (en " ", jp empty, note "restore frame row") re-blit that row from the clean plate afterwards, so the frame stays intact and descenders end at row y+14.
- Weapon/Armor Break gold plates: dark centre (x420..472) erased with copy:473, 12px white text.
- Tarot/weather/element texts: erased to transparent, redrawn with the 12px font in the original colour (255,222,200).

Untouched: 3 dark empty plates (col 3 rows 9-11), the English Dungeon List/Info/Io Folder plates, the % signs, black silhouette/shadow sprites, empty orange plates.
