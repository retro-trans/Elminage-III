# EL02_000 UI texture report

Sheet: `ANIME/EL02_000.GIM` (512x512 index-8). Spec: `work/ui/specs/EL02_000.json`, preview: `work/ui/preview/EL02_000.png`.

Japanese texts found: 77 translated + 1 monster-type kanji block (32 glyph cells) left as is. All labels fit; 0 build errors.

## Method

- 12px pink pieces (transparent background): erased to transparent over the full ink box (plus one faint antialias column where present), English drawn left-aligned with the 12px font (spacing 1, else 0) in the sampled text colour, kept inside the original ink extent unless the note says otherwise.
- Plates: text area cleaned by `copy:` of a clean column of the same plate, English drawn centred in white with the 12px font.
- SPELL LIST plate (8-row interior, too short for the 12px font): composed from letters of the sheet's own English plates (S/L/I from SKILL, P/E from PRICE, T from ITEM) via `blit:`.
- Face-icon button: interior rebuilt with fills sampled from the original (dark frame, panel, edge pixels, top-left corner square), 4 staggered lines like the original.
- Untouched (not Japanese): all English plates, ～, %, ＡＣＨＰ, △, □, `/`, `SP/`, the ▶ icon. Note: the existing English plate reads "TRAP REPOPT" (typo in the original art, left alone).

## Glyph pieces (kanji strips) and abbreviations

The strips at y80-180 are separate word pieces the game composes into labels (e.g. 射程+制限解除 = "Rng"+"No Lim", 攻撃回数+上昇 = "Atks"+"Up"). Each English word stays inside its own Japanese word box because the per-piece UV rects are not known. Abbreviations forced by width: No Lim, M/S, Rng, Crs, Act, Sp.Res, ?Name, AC-, Abl, Rce, Aln, Atks, WpnGrd, Barr., Rslt, #1/#2, Brth, Drw, Pri, Alch., Sum, FS, Cure%, Res, Avg., Btn, Sort Up/Dn, Adv., Use, Cur.

- Pieces drawn slightly outside the Japanese ink (into empty gaps): 召喚 "Sum" (1 px left), 抵抗 "Res" (1 px left), 消費 "Use" (2 px left, 1 px right), 現在 "Cur" (1 px left). If the game's UV rect is ink-tight, an edge column of the first/last letter could be clipped.

- 冒険者 plate shows "Adv." (glossary "Adventurer" is 67 px, plate holds ~46). "Party" would be an alternative if a non-glossary word is acceptable.
