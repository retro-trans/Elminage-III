# EL03_004 — place/topic buttons (UI texture report)

Sheet: `ANIME/EL03_004.GIM`. Spec: `work/ui/specs/EL03_004.json`. Preview: `work/ui/preview/EL03_004.png`.

Layout: 4 buttons x 3 states. Columns are 114 px wide: selected x=0, normal x=114, disabled x=228.
Rows are at y=0, 20, 40 and 60, and each is 18 px tall. The button style and text colours are the same
as EL02_001, so the colours, outlines and `dy` -1 come from that spec:
- selected: white with outline (60,6,107)
- normal: (220,240,241) with outline (13,15,25)
- disabled: (61,61,61) with outline (4,6,8)

Cleaning: the Small Talk row (y=60) is the reference. Its text area (x+12..x+44) is blitted from the
clean background in the same row (x+44..x+76; the offset is even, so the dither pattern is kept).
The other rows get x+12..x+110 blitted from the reference, which also redraws the right-hand swirl that
the long Japanese label had covered. The English is kept in x+14..x+90, left of the swirl.
