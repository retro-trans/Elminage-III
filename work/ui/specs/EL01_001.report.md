# EL01_001 - skill/ability name plates

Spec: work/ui/specs/EL01_001.json. Preview: work/ui/preview/EL01_001.png.

Texts found: 47 (45 plates 136x16 + 2 small status plates). Translated: 47. Untouched: VALUABLES LIST plate (already English), frame pieces, icons, the black bars and boxes in the lower half (checked with contrast boost: no text).

## Method
- Plates are 136x16 (A col x0, B col x136, C col x272, row = 16*n). Caps/border columns 0-2 and 133-135 and border rows 0 and 15 are never erased.
- Reference plates A12 (green), B12 (green, column B), C9 (blue) cleaned by blitting plateau texture (rel x 26-44 and 88-106) over the text (rel x 52-88). Every other plate gets rows 1-14, rel x 3-132 blitted from its reference (B13-B15 blue use C9).
- Small plates: interior x420-473 refilled row by row with the sampled navy colours, grey top line (row 82/102) redrawn, gold bottom line pixels the glyphs touched restored from the mirror side, 3 stray low-alpha glyph pixels above the plates cleared.
- Text: 16px game font, white (no outline), centred, style inset 16 (strings wider than 114 px fall back to spacing 0). Small plates: 16px spacing 0, colour 235.

## Open points
- 16px descenders (p, g, y) reach plate row 15 (the light bottom border line) by 1 px; no outline is drawn because a 1px outline would spill into row 0 and into the next plate. Cap tops stay on row 1, like the Japanese.
- Text is plain white; the original Japanese had a white-to-silver vertical gradient and a dark shadow, which img_text cannot reproduce without the outline problem above.
- tools/img_text.py ignores a label-level `fonts` key (prefs are read only from `style`), contrary to docs/agent_prompts/ui_texture.md. Not needed here; not edited.
- 追撃: JOB_EX "Follow-up" vs glossary "Pursuit" (see B3).
- WPN BRK / ARM BRK are new abbreviations, please confirm.
